# React User Dashboard

This project is a simple user dashboard. It demonstrates the use of React with TypeScript, fake API integration, clean component structure, and basic UI state management.

---

# Tech Stack

- React JS
- TypeScript
- Vite
- Axios
- Fake API: JSONPlaceholder

---

# Features

- User list displayed in the left panel
- User details loaded when a user is selected
- Profile tab selected by default
- Contact tab displays contact details (mobile, email, skype)
- All fields are read-only
- Dummy action buttons included
- Fake API integration
- Clean and modular component-based architecture

## Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/omkar932/user-dashboard.git
cd user-dashboard
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```

Open in browser: http://localhost:5173
